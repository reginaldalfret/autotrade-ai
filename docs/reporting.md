# AutoTrade AI — PDF & Performance Reporting Specifications

## Product & Report Branding
All generated reports and summaries must prominently display the project branding:
```
AutoTrade AI
Daily Paper Trading Report
```

## Report Types & Standards
- **Daily Individual Model PDFs**: Comprehensive breakdown of decisions, trades, slippage, costs, P&L, and equity curve per model.
- **Daily Multi-Model Summary Report**: Side-by-side comparative ranking and tournament leaderboard across all 8 local LLMs.
- **Pre-Rendering Hard Validation**: Zero unverified trades, verified P&L reconciliation against starting balances, and deterministic cost deduplication prior to rendering.
